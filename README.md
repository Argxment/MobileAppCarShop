Современное мобильное приложение на Kotlin, разработанное для демонстрации навыков мобильной разработки, работы с базами данных и управления пользовательскими сессиями.

## 📖 Описание
**CarShopProjectMobile** — это полноценное Android-приложение, реализующее основные архитектурные паттерны. Проект включает в себя систему авторизации, административную панель и функционал корзины покупок.

## ✨ Основные функции
* 🔐 **Авторизация и регистрация:** Реализованы экраны входа и регистрации пользователей.
* 👑 **Админ-панель:** Специальный интерфейс для управления контентом (AdminActivity).
* 🛒 **Корзина:** Удобный менеджер покупок и адаптеры для списков (CartManager, CartAdapter).
* 🗄 **База данных:** Локальное хранение данных через SQLite (DBHelper).
* 🔄 **Session Management:** Сохранение статуса пользователя между запусками приложения.

## 🛠 Стек технологий
* **Язык:** Kotlin
* **UI:** Android XML Layouts
* **Сборка:** Gradle (Kotlin DSL)
* **Хранение:** SQLite

## 🚀 Запуск
1. Склонируйте репозиторий.
2. Откройте проект в **Android Studio**.
3. Дождитесь синхронизации Gradle и нажмите **Run**.
